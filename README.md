# 차곡 — 나만 쓰는 가계부 (GitHub 전용)

평소에는 **PIN 숫자 4자리**로 여는 나만의 가계부입니다. 다른 서비스 없이 **GitHub만** 씁니다. 어느 노트북이나 데스크톱에서 열어도 같은 기록이 보입니다. 화면 디자인, 메뉴, 계산 방식은 기존 차곡과 같습니다.

## 구조

| 저장소 | 공개 여부 | 들어 있는 것 |
| --- | --- | --- |
| 사이트 저장소 (예: `chagog`) | Public | 화면 코드, 비밀번호로 잠긴 설정(`config.js`) |
| 기록 저장소 (예: `chagog-data`) | **Private** | 암호화된 가계부 파일 하나(`ledger.enc.json`) |

- 가계부 기록은 **내 브라우저에서 비밀번호로 암호화된 뒤** 비공개 기록 저장소에 저장됩니다. GitHub에도 암호화된 상태로만 올라갑니다.
- 사이트 주소를 누가 알아내도 **잠금 화면만** 보입니다. 비밀번호가 없으면 기록 저장소에 접근할 열쇠(토큰)도, 기록을 풀 열쇠도 꺼낼 수 없습니다.
- **긴 비밀번호와 PIN 4자리를 함께 씁니다.** 긴 비밀번호는 새 기기를 처음 등록할 때 한 번만 쓰고, 그 기기에서는 이후 PIN 4자리로 엽니다. PIN은 기기마다 따로 정하며, 그 기기 안에만 저장됩니다.
- 사이트 저장소를 Public으로 두는 이유는 무료 GitHub Pages가 공개 저장소에서만 동작하기 때문입니다. 그 안에 기록은 없습니다.

## 처음 만드는 순서

### 1. 기존 기록 백업
지금 쓰던 가계부에서 왼쪽 **↓ 데이터 백업**으로 JSON 파일을 받아 둡니다.

### 2. 기록 저장소 만들기 (Private)
GitHub에 로그인 → 오른쪽 위 **+** → **New repository**
- Repository name: `chagog-data`
- **Private** 선택
- **Create repository**

### 3. 토큰 만들기 (기록 저장소 전용 열쇠)
GitHub 오른쪽 위 프로필 → **Settings** → 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
- Token name: `chagog`
- Expiration: 원하는 기간(만료되면 7단계처럼 새 토큰으로 바꾸면 됩니다)
- Repository access: **Only select repositories** → `chagog-data` 하나만 선택
- Permissions → Repository permissions → **Contents: Read and write**
- **Generate token** → 나온 토큰(`github_pat_…`)을 복사해 둡니다. 이 화면을 닫으면 다시 볼 수 없습니다.

### 4. 사이트 저장소 만들고 Pages 켜기
1. **New repository** → 이름 `chagog` → **Public** → **Create repository**
2. **uploading an existing file** 링크(또는 Add file → Upload files)를 누르고, 압축을 푼 `chagog-ledger` 폴더 **안의** 파일과 폴더를 모두 끌어다 놓은 뒤 **Commit changes**
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → Save
4. 1~2분 뒤 같은 화면에 주소가 나옵니다. 예: `https://아이디.github.io/chagog/`

### 5. 설정 만들기
1. `https://아이디.github.io/chagog/setup.html` 을 엽니다.
2. **처음 설정**에 GitHub 아이디, 기록 저장소 이름(`chagog-data`), 3단계 토큰, 가계부 비밀번호를 넣고 **확인하고 설정 만들기**를 누릅니다. 저장소가 Private인지, 토큰이 맞는지 자동으로 확인합니다.
3. 나온 내용을 **복사하기** → 사이트 저장소에서 `config.js` 열기 → 연필(✏️) → 원래 내용을 **전부 지우고** 붙여넣기 → **Commit changes**

### 6. 이 기기 등록하고 기록 불러오기
1~2분 뒤 가계부 주소를 엽니다. 처음 여는 기기에서는 **긴 비밀번호**와 이 기기에서 쓸 **PIN 4자리**를 넣고 **이 기기 등록하고 열기**를 누릅니다. "새 가계부" 상태로 열리면 왼쪽 **↑ 데이터 불러오기**로 1단계 JSON을 넣습니다.

다음부터 이 기기에서는 PIN 4자리만 누르면 열립니다. 다른 노트북·데스크톱에서는 같은 주소를 열고 같은 방식으로 한 번 등록하면, 그 뒤로는 그 기기에서도 PIN으로 열리고 같은 기록이 보입니다.

## 나중에 할 일

### 7. 토큰이 만료됐거나 긴 비밀번호를 바꾸고 싶을 때
`setup.html` → **토큰·긴 비밀번호 변경** → 현재 긴 비밀번호와 새 토큰/새 긴 비밀번호를 넣고 → 나온 내용으로 `config.js`를 다시 바꿉니다. 기록은 그대로 열립니다.
- 긴 비밀번호만 바꿨다면: 이미 등록된 기기는 PIN 그대로 열립니다.
- 토큰을 바꿨다면: 각 기기가 처음 열 때 "토큰 만료" 안내와 함께 등록이 지워지고, 긴 비밀번호로 한 번 다시 등록하면 됩니다.

### 8. PIN을 바꾸거나 잊었을 때
잠금 화면의 **PIN을 잊었어요 · 이 기기 등록 다시 하기**를 누르고, 긴 비밀번호로 다시 등록하면서 새 PIN을 정합니다. 기록은 지워지지 않습니다.

## 꼭 알아 둘 점
- **PIN을 5번 틀리면** 그 기기의 등록이 지워집니다. 기록은 그대로이고, 긴 비밀번호로 다시 등록하면 됩니다.
- PIN 4자리는 **이미 등록한 내 기기**를 지키는 용도입니다. 노트북 자체의 로그인 잠금도 켜 두세요. 공용 PC나 남의 기기에서는 등록하지 마세요(쓴 뒤에는 **PIN을 잊었어요 · 이 기기 등록 다시 하기**로 등록을 지우세요).
- 브라우저의 사이트 데이터를 지우거나 시크릿 창을 쓰면 등록이 사라집니다. 긴 비밀번호로 다시 등록하면 됩니다.
- **긴 비밀번호를 잊으면 기록을 되살릴 방법이 없습니다.** 저도, GitHub도 풀 수 없습니다. 가끔 **↓ 데이터 백업**을 받아 안전한 곳에 보관하세요.
- **긴 비밀번호는 정말 길게** 정하세요(10자 이상, 짧은 문장형 추천). 잠긴 설정 파일이 공개 저장소에 있어서, 누군가 그 파일을 받아 무작위로 맞춰 보는 시도를 할 수 있기 때문입니다. 이 자리에 4자리 숫자를 쓰면 몇 시간 안에 풀릴 수 있어서, 4자리는 기기 안에서만 쓰도록 나눠 두었습니다.
- 토큰이나 비밀번호를 `config.js`나 다른 파일에 **직접 적어 올리지 마세요.** 반드시 `setup.html`이 만들어 준 잠긴 내용만 넣습니다.
- 새로고침하거나 창을 닫으면 다시 PIN을 물어봅니다. 30분 동안 아무것도 안 하면 자동으로 잠깁니다.
- 두 기기에서 동시에 열어 두면 15초마다 서로의 변경을 확인합니다. 서로 다른 항목을 고쳤으면 자동으로 합치고, 같은 칸을 다르게 고쳤으면 덮어쓰지 않고 멈춥니다.
- 저장할 때마다 기록 저장소에 커밋이 하나씩 쌓입니다(암호화된 상태). 그만큼 이전 버전이 남는 셈이라 기록 보호에도 도움이 됩니다.

## 계산
기본 집계 기간은 해당 월 21일~다음 달 20일이며 달력 월 보기로 바꿀 수 있습니다.
실지출 = 결제 금액 − 할인 및 엔빵.
계좌별 이번 달 사용은 이월·기타 분류를 빼고, 이월·기타는 해당 분류 거래를 합산합니다.
잔여 예산 = 배정 예산 − 이번 달 사용 − 이월·기타. 전월 잔액을 자동 승계하지 않습니다.
**그래프(월별 지출 흐름, 지출 비중)는 변동지출만** 보여 줍니다. 고정지출(적금·주식·모임 등)은 전부 제외하고, 변동지출 중 `적금` 분류도 제외합니다. 금액 카드와 표에는 고정지출이 그대로 포함됩니다.

고정지출은 분류 기준으로 **모임 / 적금 / 주식**으로 나눠 보여 줍니다(대시보드 금액 카드·월간 현황표·연간 표, 고정지출 화면). 셋 외의 분류가 있으면 "그 외"로 따로 표시합니다.

## 매월 자동 적용 (고정지출, 카드·계좌 예산)
- 한 번 입력해 두면 다음 달부터 **같은 내용이 자동으로 적용**됩니다. 고정지출은 이번 달까지만 채워지고, 아직 오지 않은 달은 그 달이 되면 채워집니다.
- 어떤 달에서 수정·삭제·추가하면 **그 달부터** 바뀐 내용이 적용되고 다음 달에도 이어집니다. 이전 달은 바뀌지 않습니다.
- 자동 적용된 고정지출에는 날짜 옆에 ↻ 표시가 붙습니다.

## 세부 지출 내역 표
- 엑셀과 같은 형식으로 **사용 내역(분류) → 세부 사용 내역**마다 지출 금액을 보여 줍니다. 기록이 없는 세부 내역은 `-`로 표시됩니다.
- **지출 금액은 변동지출 기록에서 자동으로** 채워집니다(실지출 = 결제 금액 − 할인 및 엔빵). 기본 목록에 없는 세부 내역으로 기록하면 그 분류 아래에 자동으로 한 줄이 추가됩니다.
- **입금 금액**은 분류별로 직접 입력합니다(**입금 금액 편집**). 입력한 달부터 적용되고 다음 달에도 같은 금액이 이어집니다. 분류 합계 칸에 입금 대비 사용률 막대가 표시되고, 넘으면 주황색으로 바뀝니다.
- **계좌 구분 ‘기타’**: 출장비·부수입으로 충당하는 지출은 계좌 구분을 **기타**로 기록합니다. 세부 지출 금액 칸에는 그대로 보이지만 **분류 합계와 사용률에서는 빠집니다**(칸 아래 "계좌 기타 ○원 제외").
- 기본 세부 목록은 `app.js`의 `DETAIL_TEMPLATE`에서 바꿀 수 있습니다.

## 출장비·부수입 (수입 → 계좌 기타)
- 출장비나 부수입이 들어오면 **수입 관리**에 입력하고 **계좌 구분을 기타**로 둡니다.
- 그 돈으로 쓴 지출은 변동지출에서 **계좌 구분을 기타**로 기록합니다.
- **카드·계좌 예산** 화면에 ‘기타’ 계좌 줄이 생겨, 들어온 출장비(수입 입금)에서 쓴 금액을 뺀 잔액을 보여 줍니다. 다른 계좌도 수입에 계좌 구분을 넣으면 같은 방식으로 잡힙니다.

## 엑셀 가져오기 (복사·붙여넣기 / 파일)
- 변동지출 · 고정지출 · 수입 관리 화면의 내역 표 오른쪽 위 **📋 엑셀 가져오기**를 누릅니다.
- 엑셀에서 표를 **제목 줄까지 포함해** 복사해 붙여넣거나, 엑셀 파일(.xlsx)·CSV를 고릅니다. 시트가 여러 개면 보고 있는 달(예: "8월") 시트를 먼저 고릅니다.
- 제목 줄(날짜, 구분, 지출 내역, 결제 금액, 할인 및 엔빵, 실지출, 카드, 계좌, 비고 등)을 보고 **열을 자동으로 맞추고**, 미리 보기에서 바꿀 수 있습니다.
- ₩, 쉼표, 엑셀 회계 서식의 `-`(0원)를 알아서 읽습니다. 날짜가 빈 줄은 선택한 달의 시작일로 넣고, 연도 없는 날짜(8/22)는 보고 있는 달 기준으로 연도를 붙입니다. 결제 금액이 빈 변동지출은 NA로 들어갑니다.
- 합계 줄은 건너뛰고, **이미 있는 같은 기록도 건너뜁니다**(같은 표를 두 번 붙여넣어도 중복되지 않음). 읽지 못한 줄은 몇 번째 줄인지 알려 줍니다.
- .xlsx 파일을 열 때만 SheetJS(jsDelivr)를 불러옵니다. 인터넷이 안 되면 복사·붙여넣기를 쓰면 됩니다.

## 세부지출내역 · 월간/연간 비교
- 위쪽 카드: 이번 달 변동지출을 **지난달 · 최근 12개월 평균 · 작년 같은 달**과 비교해 얼마나 더/덜 썼는지 보여 줍니다(▲ 더 씀, ▼ 덜 씀).
- **월별 추이** 그래프: 최근 12개월 변동지출 막대(이번 달은 진한 색)와 최근 12개월 평균 점선.
- **분류별 비교** 표: 분류마다 이번 달과 비교 기준(지난달 / 최근 3개월 평균 / 최근 12개월 평균 / 작년 같은 달 중 선택)을 금액·차이·막대로 비교합니다.
- 모두 변동지출 기준이며 적금 분류와 고정지출은 빠집니다. 평균은 **기록이 있는 달만** 계산해서, 가계부를 쓰기 전의 빈 달 때문에 평균이 낮아지지 않습니다.

## 변동지출 내역 필터
검색, 분류 외에 **카드 · 계좌 · 날짜 범위 · 실지출 금액 범위 · 정렬**(최신순, 오래된순, 실지출 큰 순/작은 순)로 걸러 볼 수 있습니다. 카드·계좌가 비어 있는 기록은 "카드 NA", "계좌 NA"로 골라 볼 수 있고, **필터 초기화**로 한 번에 풀 수 있습니다. 위쪽 "현재 조회 합계" 카드는 걸러진 기록의 합계입니다.

## 변동지출 NA(미입력)
- 날짜 외의 칸은 비워 둔 채 저장할 수 있고, 빈칸은 **NA**로 표시됩니다. 금액이 NA인 기록은 0원으로 계산됩니다.
- 변동지출 화면의 **NA 기록만 보기**로 모아 보고, **수정**으로 나중에 채우면 됩니다.

## 파일 구성
- `index.html`, `style.css`, `app.js`, `core.js`, `merge.js`: 화면과 계산 (기존과 같음)
- `github-sync.js`: 잠금 화면, 암호화 저장, 기기 간 동기화
- `importer.js`: 엑셀 복사·붙여넣기 / 파일 가져오기
- `device.js`: 기기 등록과 PIN 4자리 (5번 틀리면 등록 삭제)
- `vault.js`: 암호화 도구 (PBKDF2-SHA256 60만 회 → AES-GCM 256)
- `setup.html`, `setup.js`: 처음 설정, 토큰·비밀번호 변경
- `config.js`: 비밀번호로 잠긴 설정 (setup.html이 만들어 줌)
- `tests/`: 계산·병합 테스트, 화면 테스트(`node tests/ui.test.mjs`), 전체 흐름 테스트(`node tests/e2e.test.mjs`) · 앞의 두 개 외에는 `npm i jsdom@24 fake-indexeddb@6` 필요
